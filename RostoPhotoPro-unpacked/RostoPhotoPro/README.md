### 🚀 البدء السريع

#### 1. استنساخ المشروع
```bash
git clone https://github.com/yourusername/RostoPhotoPro.git
cd RostoPhotoPro
```

#### 2. فتح المشروع في Android Studio
- اضغط على **File → Open** واختر مجلد المشروع
- انتظر حتى تنتهي عملية Gradle من المزامنة

#### 3. بناء وتشغيل التطبيق
```bash
# بناء APK تطوير
./gradlew assembleDebug

# بناء APK الإصدار النهائي (مع تصغير الحجم)
./gradlew assembleRelease

# تشغيل على المحاكي أو الجهاز
./gradlew installDebug
```

#### 4. التثبيت على جهازك
```bash
# يمكنك نقل ملف APK من build/outputs/apk/ وتثبيته مباشرة
adb install app/build/outputs/apk/debug/app-debug.apk
```

### 🛠️ المكتبات الرئيسية

#### واجهات المستخدم
- **Jetpack Compose** - بناء واجهات معاصرة وديناميكية

- **Navigation Compose** - التنقل بين الشاشات

- **Android Graphics** - معالجة بيتماب والرسومات

- **TensorFlow Lite** - تشغيل نماذج ML محلياً
- **TensorFlow Lite GPU** - معالجة سريعة باستخدام GPU

#### عمليات غير متزامنة
- **Kotlin Coroutines** - إدارة العمليات بكفاءة
