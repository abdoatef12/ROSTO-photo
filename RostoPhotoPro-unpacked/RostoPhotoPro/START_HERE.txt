الخطوات الخمس الأساسية:

1️⃣  انسخ هذا المجلد على جهازك (RostoPhotoPro)

2️⃣  افتح Android Studio
    → File → Open → اختر مجلد RostoPhotoPro
    → انتظر Gradle Sync ينتهي

3️⃣  شغّل التطبيق
    → اضغط الزر الأخضر ▶️ Run (أو اضغط Shift+F10)
    → اختر محاكي أو جهازك
    → انتظر التطبيق يفتح

4️⃣  اختبر الميزات
    → اضغط "فتح صورة" واختر صورة
    → اضغط أزرار الأدوات
    → جرّب السطوع والتباين والفلاتر

5️⃣  رفع على GitHub (اختياري)
    → اقرأ ملف: UPLOAD_GITHUB_NO_TOKEN.md
    → اتبع الخطوات بالضبط
